# Fraud Detection — детекция мошеннических операций нейросетью

Лабораторная работа по курсу «Машинное обучение»: построение пайплайна от
сырого CSV с банковскими транзакциями до обученной на PyTorch нейросети,
предсказывающей вероятность мошенничества, с корректной (без утечек данных)
оценкой качества на несбалансированном датасете (~1.7% фрода).

Полное техническое задание и пошаговый роадмап — в [`TZ_i_roadmap.md`](TZ_i_roadmap.md).

## Структура репозитория

| Файл | Описание |
|---|---|
| `bank_transactions.csv` | Датасет банковских транзакций (сгенерированный, «грязный» намеренно) |
| `data_dictionary.md` | Словарь колонок датасета и разбор ловушек: утечки данных, дисбаланс классов, шум в метках |
| `generate_dataset.py` | Скрипт генерации датасета (можно перегенерировать с другим объёмом/сидом) |
| `eda_check.py` / `eda_overview.png` | Черновой разведочный анализ для sanity-check данных |
| `lab_skeleton.ipynb` | Заготовка итогового ноутбука со структурой из роадмапа |
| `TZ_i_roadmap.md` | Техническое задание и подробный роадмап по этапам работы |

## Стек

- **numpy / pandas / matplotlib / seaborn** — обработка данных, EDA, визуализация
- **PyTorch** — нейросеть, обучение, инференс
- Разбиение выборки, масштабирование и метрики реализуются вручную (без
  scikit-learn) — это осознанное ограничение задания, см. оговорку в начале
  `TZ_i_roadmap.md`

## Ключевые требования пайплайна

- Разбиение train/val/test **по времени**, не случайное
- Масштабирование признаков, посчитанное **только по train**
- Нейросеть с учётом дисбаланса классов (`pos_weight` в `BCEWithLogitsLoss`)
- Метрики: precision, recall, F1, PR-AUC, confusion matrix — не accuracy
- Осознанный подбор порога классификации и анализ ошибок (FP/FN)

## Как запустить

```bash
pip3 install torch numpy pandas matplotlib seaborn jupyter
jupyter notebook lab_skeleton.ipynb
```

Ноутбук должен выполняться сверху вниз без ошибок (`Restart & Run All`).
